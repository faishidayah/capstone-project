# capstone-project

a simple program to manage a library database, there are several menus that allow us to manipulate the database including:
- 🪟👁️📖 see the entire list of books in the library database,
- ➕🆕📕 add a new book list,
- ✅🔄📚 update/change book data
- 🗑️🚮📒 delete book data.

tools :
- python
