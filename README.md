📚 Library Book Management System (Python CLI)

This is a simple Python-based CLI application designed to manage a collection of library books using basic CRUD (Create, Read, Update, Delete) operations. The program allows users to view the complete book list, add new entries, update book details and stock, and delete records. It is well-suited for administrative use in bookstores or libraries, providing an efficient way to maintain book inventory.
